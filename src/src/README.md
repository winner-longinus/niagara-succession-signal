Source Code

Purpose

This folder contains reusable Python code used to process data, perform analysis, build models, and generate project outputs.

What Belongs Here

Code may include:

- Data processing functions
- Data cleaning functions
- Feature engineering
- Statistical analysis functions
- Forecasting models
- Model evaluation
- Visualization functions
- Utility functions

Organization

As the project grows, code may be organized into modules such as:

- "data_processing.py"
- "feature_engineering.py"
- "forecasting.py"
- "model_evaluation.py"
- "visualization.py"

The exact structure will evolve with the project.

Working Principles

Code should be:

- Reusable
- Understandable
- Documented where necessary
- Version controlled
- Consistent with the project's reproducibility requirements

Important logic should not exist only inside individual notebooks when it can be converted into reusable functions.

Relationship to the Project

The "src/" folder contains the reusable computational components that transform project data into analytical results, forecasts, visualizations, and other outputs.
